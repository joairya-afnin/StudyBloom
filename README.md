
# 🌷 StudyBloom — Personal Syllabus Tracker

StudyBloom is a simple, pastel-themed study planner designed to help students organize their courses, track syllabus progress, and manage their study time.

## ✨ Features

- 📚 **Course Management** — Add, edit, and delete courses.
- 📝 **Syllabus Tracking** — Add topics, mark them as completed, edit them, or delete them.
- 📊 **Progress Tracking** — View course progress and overall syllabus completion.
- ⏱️ **Study Timer** — Track time spent studying a specific course and topic.
- 💾 **Local Storage** — Save course information and study sessions in your browser.
- 📱 **Responsive Design** — A layout designed for desktop and mobile screens.

## 🎨 Design

StudyBloom uses a soft pastel color palette featuring lavender, blush pink, and sage green to create a calm and welcoming study environment.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Browser Local Storage

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

An internet connection is required for the Google Fonts and Tailwind CSS CDN resources used by the project.
